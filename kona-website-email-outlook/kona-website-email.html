The editing experience

Easy Editing with Elementor

Elementor is a visual page builder inside WordPress. Instead of needing to edit code to make many common changes, you can visually edit the page and see what you're changing.

Think of it like editing a document where the page looks just as visitors will see it. You click on the part you want to change, update it, and preview the result before publishing. It was chosen specifically to make the website easier for you to manage.

How it works

Three simple steps
1 Edit the page visually

Open any page in Elementor and it appears just as it does on the website, with the editing options on the left.

  Elementor · Our Beliefs page
2 Click and change content

Click a section, such as the service times box on the homepage, and its content and settings open for editing.

  Elementor · Home page
3 See your changes while you work

Changes appear on the page right away, so you can check how they look before you publish.

  Elementor · Events page

Common changes you can make include:

•  Editing text

•  Replacing images

•  Updating buttons

•  Changing sections

•  Adjusting layouts

•  Updating page content

Many everyday content updates can be handled directly through the visual editor, while more advanced changes can still be handled by me when needed.
